
  Airport Data Management System

  Overview
This project is a simple airport data management system built for coursework. It allows users to input an airport code and year, then returns flight statistics such as number of flights and total flight hours.

  Features:
- Input airport code and year
- Display flight statistics
- Basic data visualization 
- Simple user interaction system

  Technologies Used:
- Python 
- Basic file handling / data structures
  
  Purpose :
Built as a coursework project to demonstrate data handling, user input processing, and basic analytics.

  How to Run:
Run the main Python file and follow the on-screen instructions.
